# Focus Desk

모든 프로젝트와 아이디어가 자기만의 공간을 갖는 데스크탑 워크스페이스.
탭·위젯·리소스를 공간에 펼쳐두고 줌으로 오가며 쓴다. Electron + React + TypeScript.

## 문서
- [docs/STATUS.md](docs/STATUS.md) — **출시까지 남은 일** (스타팅 포인트)
- [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) — 코드 구조
- [docs/VISION.md](docs/VISION.md) — 컨셉과 경계

## 실행
```bash
npm install
npm run dev
```
