## 1. 이 디자인이 뭘 하려는 건가

**위젯은 유리가 아니라 불투명한 물체다. 사용자가 고른 배경 위에 놓여 있다.**

반투명 표면은 배경 휘도를 그대로 물려받는다. 이 앱은 배경이 네 가지(밝은 사진 / 어두운 사진 / 밝은 단색 / 어두운 단색)라 반투명으로는 한 벌이 성립하지 않는다. 사진의 밝은 얼룩마다 글자 대비가 달라진다.

- **글자를 이고 있는 면은 전부 불투명.** 반투명은 어디에도 안 쓴다
- 배경과 분리되는 문제는 **그림자 한 벌**로 푼다. 테두리는 없다 (아래 4장)
- 감성은 투명도가 아니라 다른 데서 낸다 — 위젯을 띄엄띄엄 놓아 배경이 넓게 보이게, 표면은 흰 카드(어두우면 `#1F1F21`), 그림자는 넓고 부드럽게, 화면 전체에 고운 그레인
- **명암 극성은 배경이 정한다.** 공간을 고르면 배경·이름·극성이 한 번에 바뀐다. 그림과 토큰이 갈라질 수 없는 구조여야 한다 (이게 지금 앱의 9-2 버그다)

## 2. 색

액센트는 **번트 앰버 하나**. 카드 면은 **무채색 두 값**(밝음 흰색 / 어두움 `#1F1F21`)이고 공간 색을 안 띤다. 글자는 따뜻한 잉크 그대로다.

| 토큰 | 밝음 | 어두움 |
|---|---|---|
| `--surface` | `#FFFFFF` | `#1F1F21` |
| `--surface-2` (면 위 타일·웹앱 타일) | 잉크 6% + 면 | 잉크 6% + 면 |
| `--plate` (남의 웹페이지 자리) | 잉크 11% + 면 | 잉크 11% + 면 |
| `--text` | `#1E1C19` | `#F0EDE7` |
| `--text-2` | `#5C574F` | `#A9A29A` |
| `--text-3` | `#726C62` | `#948D83` |
| `--accent` | `#A9581B` | `#E9A75F` |
| `--accent-ink` (액센트 위 글자) | `#FFF7EF` | `#231F1A` |
| `--accent-soft` | `rgba(169,88,27,.12)` | `rgba(233,167,95,.15)` |
| `--danger` (위험 상태) | `#A3231A` | `#E98B78` |

**검증된 대비** (sRGB 상대 휘도, AA 기준 본문 4.5 / UI 3.0)

| | 본문 | 보조 | 최하위 | 액센트 | 액센트 버튼 글자 |
|---|---|---|---|---|---|
| 밝음 | 17.00 | ≈6.6 | ≈4.9 | 5.12 | 4.83 |
| 어두움 | 14.08 | ≈6.6 | ≈4.9 | 7.96 | 7.92 |

보조·최하위는 `inkStep`이 면마다 맞추는 목표값이다(아래). 2026-09-15 면 값 기준.

**글자 셋은 이 표의 값이 나오게 계산한다.** `--text-2`·`--text-3`을 잉크의 알파로 어림하면
면이 배경 색조를 띠는 순간 배경마다 다른 대비가 나온다(재보니 보조 2.75~6.07, 최하위 1.78~2.66).
`backgrounds.ts`의 `inkStep`이 잉크의 색조·채도는 두고 밝기만 면 쪽으로 옮겨 6.6 / 4.9에 맞춘다.
`--ink-soft`·`--ink-faint`가 그 결과이고 `.t-soft`·`.t-faint`가 읽는다.
**본문보다 진해지지는 않는다** — 밝은 배경에 Dark를 걸면 본문 자체가 4.63이라 6.6을 낼 자리가 없다.
그때는 셋이 겹치고 위계는 굵기가 낸다(3장). `backgroundTokens.test.ts`가 지킨다.

**액센트를 쓰는 곳** — 여기 말고는 어디에도 유채색이 없다.
기본 버튼 · 타이머 재생 버튼 · 활성 공간 표시 막대 · 타이머 진행 막대 · 체크된 체크박스 · 브라우저 로딩 막대 · 볼륨 페이더 캡 · 포커스 링 · 선택 표시 · 드롭 표시 · Retry

**액센트는 테마가 아니라 값 층이 정한다.** 앱은 테마가 8종이지만 액센트는 극성별 두 값뿐이고,
`:root` / `:root[data-polarity='light']`에 있다. 테마가 아직 들고 있는 것은 배경 그림·분위기·
글자색·테두리색이다. `--accent-ink`는 액센트를 깔았을 때 그 위에 얹는 글자색이다.

**라디우스 예외 3종** — 시계 문자판·바늘, 투어 스포트라이트 링, div로 그린 아이콘 글리프.
셋 다 면·컨트롤·표식이 아니라 그림이라 눈금 대상이 아니다.

**`--danger`는 액센트가 아니라 상태 색이다.** 지우기·실패에만 쓰고 그 밖에는 안 나온다.
평소에는 회색이고 가리켰을 때만 빨개진다(`.t-danger:hover`) — 타일마다 빨간 ✕가 붙어 있으면
경고가 늘어선 것으로 읽힌다. 액센트와 같은 따뜻한 계열에서 뽑아 한 화면에 두 색 온도가
안 섞이게 했다: 어두운 값 `#E98B78`은 액센트 `#E9A75F`와 빨강 채널이 같다.
대비는 면 위에서 밝음 7.47 / 어두움 6.60 (AA 본문 4.5 기준).

**면은 공간 색을 안 띤다** (2026-09-14 리뉴얼). 카드·레일·독·패널 면은 극성마다 한 값이다.
예전에는 배경 색조를 면에 섞었는데, 방마다 카드가 민트·분홍·보라로 나오고 회색·흰색 바탕에서도
분홍 카드가 나왔다. 공간을 바꿨다는 신호는 배경 사진과 레일 썸네일이 준다. 사진 색은 그림자
색조(`--shadow-tint`)에만 남는다.

**카드 밝기 기본값**
- 사진 배경: 밝은 카드. 어두운 카드는 Atmosphere에서 고른다
- 단색: 팔레트가 색마다 정한 값(`SOLID_COLORS`의 `cards`). 강한 색(Tomato·Cobalt·Saffron·Violet)은 휘도와 상관없이 흰 카드. 목록에 없는 색은 휘도로 판정
- 비네트·격자 선은 카드가 아니라 배경 그림의 밝기를 따른다

구현은 [backgrounds.ts](../src/spaces/backgrounds.ts)의 `backgroundTokens`·`cardsLightOn`과
[useTheme.ts](../src/themes/useTheme.ts)의 `useGround`. 계약은 `backgroundTokens.test.ts`가 지킨다.

**색 마크는 카드 전체를 옅게 칠한다** — 밝음 16% / 어두움 22%(`--mark-fill`). 칠한 면 위 보조·최하위
글자는 본문 쪽으로 당긴다(`--mark-ink-pull`). 왼쪽 막대는 줌아웃하면 안 보여서 없앴다.

**단색 팔레트 12색** — 어두운 넷(Ink·Graphite·Midnight·Forest) / 밝은 넷(Cloud·Canvas·Mist·Sage) /
강한 색 넷(Tomato·Cobalt·Saffron·Violet). 격자는 기본 꺼짐이고 Atmosphere의 Grid로 켠다.

**위젯 색 마크(`--mark`)는 액센트를 안 따른다** (2026-09-08에 정함)

여덟 색([widgetColors.ts](../src/widgets/widgetColors.ts))은 "이것들이 한 묶음이다"를 나타내는
분류 색이다. 액센트 계열에서 여덟을 다시 뽑는 안은 버렸다 — 한 색조에서 여덟을 갈라내면 구분이
안 되고, 액센트는 배경을 따라 바뀌므로 방을 옮길 때마다 여덟이 전부 다른 색이 되어 사용자가
붙인 분류가 안 남는다. 지금 여덟을 그대로 두고 7장에 예외를 적었다.

## 3. 글자

| 역할 | 값 | 토큰 |
|---|---|---|
| UI | IBM Plex Sans KR 400 / 500 / 600 / 700 | `--font-ui` |
| 숫자 | JetBrains Mono + `tabular-nums` (타이머·줌 배율·볼륨) | `--font-mono` |
| 세리프 | 안 쓴다 (근거 없음) | |

한글·영문을 한 글꼴로 쓴다(2026-09-15 리뉴얼). 예전 Instrument Sans에는 한글이 없어서
한글만 시스템 글꼴로 떨어졌다. 굵기마다 파일을 번들한다. **테마마다 글꼴이 갈리지 않는다** — 이전에는
Paper 테마가 UI 전체를 손글씨(Bradley Hand)로 그렸다.

- **위계는 크기가 아니라 굵기·색으로.** 제목 600 / 본문 400 / 메타 500 + `--text-3`
- 큰 글자에만 음수 트래킹. 타이머(`--text-display` 34px)에 `-0.035em`
- 라벨은 양수 트래킹 `.04em` ~ `.06em`

**스케일 6단.** 이 여섯 말고는 안 쓴다.

| 토큰 | 값 | 쓰는 곳 |
|---|---|---|
| `--text-micro` | 10px | 대문자 트래킹 라벨·뱃지·단축키 |
| `--text-meta` | 11px | 메타·보조 |
| `--text-ui` | 12px | UI 기본 — 버튼·행·입력·탭 |
| `--text-body` | 14px | 본문·카드·메모 |
| `--text-title` | 17px | 위젯·패널 제목 |
| `--text-display` | 34px | 타이머·큰 숫자 |

작은 쪽이 1px씩 촘촘한 이유: 위계를 크기가 아니라 굵기·색으로 잡으므로 UI 대부분이
10~14px 안에 산다. 큰 쪽은 역할이 하나씩이라 사이가 넓다.

**시안의 11px 하한을 안 따르고 10px을 둔 이유**: 지금 앱에서 10px 이하가 76곳이고
전부 대문자 트래킹 라벨이다. 시안은 위젯 5개짜리 정적 화면이라 이 밀도가 없었다.
10px은 대문자 트래킹 라벨 전용으로만 쓴다.

⚠️ **오프라인 앱이라 woff2를 번들해야 한다.** CDN 링크로 두면 패키징본에서 시스템 폰트로 조용히 떨어진다.

## 4. 표면 · 모양

**라디우스 3단.** 이 셋 말고는 안 쓴다.

| 토큰 | 값 | 쓰는 곳 |
|---|---|---|
| `--radius-surface` | 14px | 위젯·패널·독·레일 |
| `--radius-control` | 8px | 버튼·입력·탭·주소창 |
| `--radius-mark` | 4px | 체크박스·색 마크·작은 표식 |

**위젯 표면 (`.widget-glass`·`.glass-panel`) — 면 + 그림자 한 벌.** 테두리·헤일로·윗변 빛은 없다(2026-09-14 리뉴얼).

```css
/* 사진 위 */
--shadow-card: 0 2px 4px rgba(0,0,0,.14), 0 22px 48px -16px rgba(0,0,0,.55);
/* 단색·Paper 위 ([data-ground='color']). 색조는 배경에서 뽑는다 */
--shadow-card: 0 1px 2px rgba(var(--shadow-tint),.06), 0 16px 38px -14px rgba(var(--shadow-tint),.26);
```

- 어두운 카드는 어두운 배경에 가장자리가 묻혀서 안쪽 1px `rgba(255,255,255,.07)` 선을 둔다(`outline`, Editorial 제외)
- 단색 위 그림자는 순수 검정을 쓰지 않는다. 배경 색조로 틴트한다
- 광원 방향은 하나. 전부 위에서 아래

**선택 표시** — 강조색 2px `outline` + 반대색(`--accent-ink`) 4px 번짐. 끌어 넣을 컬럼도 같은 링.

**그림자 토큰.** 색조는 테마가 자기 배경에서 뽑아 `--shadow-tint`(`r, g, b`)로 덮어쓴다.

| 토큰 | 쓰는 곳 |
|---|---|
| `--shadow-lift` | 바닥에 붙어 있는 것 — 행·카드·입력 |
| `--shadow-card` | 카드·레일·독·패널·팝오버 |
| `--shadow-float` | 캔버스 위로 한 단 더 뜨는 위젯 미리보기(peek) |

**스페이싱 7단.** `2 / 4 / 6 / 8 / 12 / 16 / 24`px. Tailwind 눈금으로 `0.5 / 1 / 1.5 / 2 / 3 / 4 / 6`.
그 사이 값(`5` `7` `9` `10` `14`)은 안 쓴다 — 시안이 쓴 임의값들이 여기로 반올림된다.
셸이 창 가장자리에서 띄는 14px만 예외고, 그건 여백이 아니라 5장의 배치 규칙이다.

## 5. 배치

- **셸은 창 가장자리에 붙지 않는다.** 14px 여백을 두고 뜬다. 배경이 창 네 변에 다 닿는다
- **캔버스는 비대칭, 셸은 격자.** 위젯은 자유 좌표라 구도가 저절로 비대칭이 된다. 셸은 매일 8시간 쓰는 도구라 좌표가 흔들리면 안 된다
- 팝오버는 **화면 안으로 접는다.** 높이를 상수로 적어두면 줄이 늘 때마다 같이 고쳐야 하므로 그려진 높이를 재서 접는다([QuickAdd.tsx](../src/app/QuickAdd.tsx))

## 6. 움직임 · 상태

**MOTION_INTENSITY 3.** 이 앱에서 움직이는 건 사용자다 — 줌·팬·드래그. 그 위에 등장 애니메이션을 얹으면 사용자 조작과 경쟁한다.

- **자동 재생 루프 0개.** 트랜지션은 hover / `:active` / 줌 배율 변경 세 곳뿐
- `prefers-reduced-motion` 필수. 전역으로 애니메이션·트랜지션을 끈다. **끄면 사라지는 표시가 있는지 보고 대체를 준다** — 로딩 막대는 훑기를 멈추면 화면 밖에 서므로 변을 옅게 채우는 것으로 바뀐다
- **포커스 링 필수.** `:focus-visible`이 [index.css](../src/index.css)에 전역으로 있다(입력·contenteditable은 제 배경으로 대신한다). 9-1에서 넣었다

**Calm Tech = 위젯 헤더를 평소에 숨긴다.** 헤더(이름·최대화·닫기)는 30px 자리를 항상 차지하되 내용은 `opacity: 0`이고 `hover` / `focus-within`에서만 나타난다. 자리를 유지하니 레이아웃이 안 튄다.

**모든 위젯·패널이 가져야 하는 상태 네 개.** 위젯 12종은 2026-09-06에, 패널 9개·토스트 3개·온보딩은 2026-09-08에 끝났다.
로딩과 촉감은 모양이 어디서나 같아서 클래스로 있다 — `.skeleton`(들어올 내용 모양) ·
`.load-bar`(페이지 받는 중 윗변 막대) · `.press`(`:active`에 1px). 빈·에러는 무엇을 쓸지가
자리마다 달라 클래스가 없다.

| 상태 | 규칙 |
|---|---|
| 빈 | 어떻게 채우는지 알려준다. **있는 기능만 가리킨다** — 예전 예시가 "메모에서 체크된 줄을 끌어내라"였는데 그런 기능이 없다. 할 일 위젯은 아래 입력칸을 가리킨다: "Nothing to do here yet / Write your first task in the box below." |
| 로딩 | 최종 레이아웃 모양의 스켈레톤. 원형 스피너 금지 |
| 에러 | 폼은 인라인, 그 외는 위젯 안에. 무엇이 잘못됐고 어떻게 고치는지. "Save failed. / Retry" |
| 촉감 | `:active`에 `translateY(1px)` 또는 `scale(.98)` |

## 7. 금지

- **엠대시 `—`.** UI 문자열 어디에도. 주석과 이 문서에는 써도 된다
