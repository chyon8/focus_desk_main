# VISION — 컨셉과 경계

## 한 줄 정의
**"모든 프로젝트와 아이디어가 자기만의 공간을 갖는 데스크탑 워크스페이스."**
탭·위젯·리소스를 리스트가 아니라 공간에 펼쳐두고, 줌으로 오가며 쓴다.

- Your ideas deserve their own spaces. Your new desktop.

## 제품 축 (우선순위 순)
1. **공간형 워크스페이스 (코어)** — 프로젝트별 스페이스, 리소스를 자유 배치, ZUI(줌 인/아웃)
2. **브라우저 통합** — 웹 탭을 공간 안의 카드로. 스페이스별 세션(로그인) 분리
3. **감성 레이어 (차별화)** — lofi/글래스모피즘 디자인, 앰비언스 사운드, 배경 커스텀
4. **집중 도구** — 포커스 세션, 통계, 위젯(Todo/Timer/Kanban 등)
5. **데스크탑 네이티브 강점** — PiP/always-on-top 미니 모드 (웹 경쟁자가 못 하는 것)

## 타겟
여러 프로젝트를 병행하며 컨텍스트 스위칭에 지친 개인 작업자.
"분위기"가 아니라 "프로젝트 전환 비용 해결"을 사되, 감성이 머물게 만든다.

## 포지셔닝
- Kosmik(공간형 브라우저) + cramandconquer(감성 집중) 사이. "Kosmik인데 감성이 있는".
- 브라우저 **대체가 아님** → "프로젝트 리소스를 펼쳐두는 세컨드 스크린". 확장 프로그램 부재를 인정하고 싸우지 않는다.

## 하지 않을 것 (당분간)
- **3D / 캐릭터 맵** — 제외 결정 (2026-08-16). 코어 가치가 2D이고 웹 콘텐츠를 WebGL에 넣을 수 없음. 추후 배경 장식으로만 재검토 가능
- **협업/채팅** — 유저 생긴 후. 단, 데이터 모델은 나중에 CRDT 도입이 가능하게 설계
- **모바일/웹 버전** — Electron 데스크탑 온리

## 디자인 방향
- **기존 디자인 언어 유지**: 글래스모피즘(반투명 블러 위젯), lofi 감성, 배경이 비치는 깊이감, Inter 폰트, framer-motion 부드러운 전환
- 유지 이유: 감성 레이어가 차별화 축이고 MVP에서 이미 검증된 자산
- 단, 셸 레이아웃(사이드바/컨트롤바)은 ZUI에 맞게 재설계 가능
- Calm Tech 원칙: 집중 시 UI는 사라진다 (Focus Mode 유지)

## 성공 기준 (제품 관점)
- 스페이스 전환이 브라우저 창/탭 전환보다 빠르고 컨텍스트가 완전히 복원된다
- 하루 작업을 이 앱 안에서 시작하고 끝낼 수 있다
