## 다음 할 일 (순서 사용자 합의, 2026-08-16 — 그대로 유지)
1. **PiP 재설계** — 지금은 누르면 **앱 창 자체가** 380×300으로 줄고 데스크가 사라짐(D-017 방식). 원래 의도(위젯 하나만 별도 작은 창, 데스크는 유지)대로 하려면 두 번째 `BrowserWindow` + 두 창이 같은 스페이스를 보도록 동기화 필요. 안 쓸 기능이면 삭제도 선택지 — 착수 전에 사용자에게 확인
   - **딸린 작업(동의됨, 미착수):** 위젯 헤더에 "몰입" 버튼 — 클릭 한 번으로 앱 전체화면 + 위젯 최대화를 동시 적용, Esc 한 번으로 동시 해제. 지금은 영상 전체화면(위젯 안)/위젯 최대화(⛶)/앱 전체화면(⌃⌘F)이 각자 따로라 진짜 몰입까지 3번 눌러야 함
2. **사용성 QA** — UX가 최선인지, 실사용 오류 없는지 훑는 라운드
3. **바탕화면 레이어 모드**(조사 필요) — 데스크탑 배경층에 고정, 다른 앱이 위로 올라오게. macOS는 NSWindow level을 `kCGDesktopWindowLevel`로 내려야 하는데 Electron API에 없음 → 네이티브 애드온/Übersicht 방식 조사. 상호작용 유지가 관건
4. **배포 마무리**(D-027) — Developer ID 인증서 확보 → 공증 + 자동 업데이트, 앱 아이콘 제작
5. 미검증: 60fps 실측, 앰비언스 실제 소리 품질 / 정리: `legacy/` 삭제
6. Reader 위젯: 보류(D-028). 원하면 착수
