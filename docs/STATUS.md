### 0. ✅ 해결 — 팝업 차단·앱 숨김 알림 (D-076)

둘 다 **고치던 코드가 실행된 적이 없었다.** 원인은 프로브로 재현해서 확정했다.

- **팝업**: `<webview allowpopups>`를 JSX 불리언 축약으로 써서 React가 속성을 안 붙였다 → `window.open`이 null, `setWindowOpenHandler`는 호출조차 안 됨. `ALLOW_POPUPS` 스프레드로 고치고 회귀 테스트 추가([browserLinks.test.ts](../src/widgets/browserLinks.test.ts))
- **알림**: `NSRunningApplication.hide()`가 숨기면서 false를 반환 → `hiddenApps`가 늘 비어 알림도 복귀도 불가. 요청했으면 기록하도록 수정
- 실기 확인 남음: 노션 로그인 팝업이 진짜 창으로 뜨는가 / 앱 위젯을 열면 알림이 뜨고 아이콘 클릭·⌃⌥D로 복귀하는가

> 참고: 이때 맥에서 **2026-08-17 패키징본**(`release/mac-arm64`)이 계속 떠 있었다. 그 빌드에는 두 기능이 아예 없다. 실기 검증은 dev 인스턴스 하나만 띄우고 한다
